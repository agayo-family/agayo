# Подключение внешнего альбома ВК

Альбом владельца: https://vk.ru/album-241505282_311782197. Мероприятие: «AGAYO HALLOWEEN: ПОСЛЕДНЯЯ УЛЫБКА».

## Как работает новая схема

В БД сохраняются ссылка на альбом, связанное мероприятие, число фотографий и служебные сведения об изменении. Отдельные фотографии и их CDN-адреса в БД не записываются. Файлы в Blob не копируются; браузер загружает изображение напрямую с разрешённого CDN ВК. Next Image для этих кадров работает без серверной оптимизации и копирования изображения.

Список запрашивается страницами до 24 кадров. В памяти сервера используется ограниченный кеш до 60 секунд; HTML/API-кеш может временно содержать ссылки, но не создаёт записей фотографий в БД или копий файлов в Blob. При ошибке ВК сайт сообщает о недоступности, повторная загрузка страницы доступна. При первоначальном сбое галерея показывает локально загруженные кадры.

Один альбом можно связать с разными событиями: идентификаторы кадров включают мероприятие. Для кадров ВК сохранение в избранное AGAYO отключено, поскольку текущая функция избранного требует записи фотографии в локальной медиатеке. Уже загруженные фотографии и их избранное сохраняются.

## Токен: что требуется

Нужен **серверный VK API access token**, который реально принимается методом photos.get и имеет доступ к выбранному альбому. VK ID login token и токен другого приложения автоматически такими правами не обладают. Доступность выдачи нужного токена зависит от типа приложения, разрешённых методов и настроек VK; универсальную работающую кнопку выдачи токена для любого нового приложения подтвердить не удалось.

1. В официальном кабинете разработчика VK создайте/выберите приложение с разрешённым доступом к VK API и фотографиям. Для закрытого альбома авторизованная учётная запись также должна иметь право просмотра.
2. Используйте поддерживаемую этим приложением официальную процедуру авторизации и выдачи access token с нужными разрешениями. Проверьте тип токена, срок действия и photos.get для owner_id=-241505282, album_id=311782197. Не используйте сторонние сайты выдачи токенов, чужие client_id и инструкции с передачей пароля.
3. Если кабинет не позволяет получить право photos/метод недоступен, сначала решите это через официальный доступ VK API. Подстановка токена VK ID проблему не исправляет. В этом случае остаются обычная загрузка фотографий или существующий внешний источник до получения доступа.
4. В Vercel откройте нужный проект agayo-8n2v → Settings → Environment Variables. Добавьте VK_ACCESS_TOKEN для Production, при необходимости отдельно для Preview. Значение вводите только в защищённом поле. Не добавляйте NEXT_PUBLIC_, токен не присылайте в чат.
5. Примените миграцию db/016_external_gallery.sql и выложите текущую версию. При первой разрешённой записи приложение может создать отсутствующую таблицу, но штатная миграция предпочтительнее.
6. Откройте админку → Фото → выберите нужное мероприятие → вставьте ссылку альбома → «Подключить альбом ВК».
7. Сайт сначала проверит доступ к альбому и его количество кадров, затем сохранит связь. Проверьте первую страницу, «Ещё фотографии», мобильное открытие и главную.
8. После добавления/удаления кадров в ВК повторно подключите ту же ссылку, чтобы обновить количество. При открытии доступной страницы число также уточняется из ответа ВК.
9. «Отключить альбом» удаляет только связь с сайтом. Фотографии в ВК и прежние загрузки Blob остаются.

Перенос на Render меняет только место хранения защищённой переменной: Environment сервиса. Токен всё так же остаётся серверным.

## Ошибки и ограничения

- 503/ошибка токена: отсутствует, истёк или отозван VK_ACCESS_TOKEN; обновить подключение и redeploy.
- Нет доступа: проверить публичность альбома и права именно этого токена.
- Ограничение частоты/CAPTCHA: остановить повторные попытки и восстановить доступ официальным способом.
- Кадр удалён или закрыт в ВК: сайт не имеет собственной резервной копии. Это сознательный компромисс экономии.
- Подключённый альбом виден только у опубликованного, не удалённого из управления события. Не подключайте конфиденциальные альбомы: доступные серверному токену кадры станут публичными на сайте.

Справка метода: [официальная документация photos.get](https://dev.vk.com/ru/method/photos.get). Текущий порядок выдачи токена необходимо проверить в вашем кабинете VK; реальный альбом без внесённого владельцем токена в этой работе не проверялся.
