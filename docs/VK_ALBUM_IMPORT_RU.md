# ВК: внешние альбомы вместо копирования в Blob

Актуальная инструкция: [VK_EXTERNAL_ALBUM_RU.md](VK_EXTERNAL_ALBUM_RU.md).

С 16 октября 2026 года пользователь выбрал хранение файлов у ВК. Прежняя очередь импорта в Blob отключена (старое действие API возвращает410). Существующие ранее загруженные фотографии сохраняются. БД хранит только ссылку и общие сведения альбома; отдельные CDN-адреса и файлы не записываются.
