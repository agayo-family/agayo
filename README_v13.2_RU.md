# AGAYO v13.2 — аккаунт, избранное и админка

Патч подготовлен поверх текущей ветки `main` репозитория `agayo-family/agayo` на 14.09.2026.

## Что исправлено

1. **Роли и права в админке**
   - исправлена ошибка `admin_memberships_permissions_check`;
   - миграция заменяет устаревший CHECK на структурную проверку JSON-массива;
   - API ролей формирует `permissions` как настоящий JSONB-массив и по-прежнему проверяет каждое право по серверному списку.

2. **Редактирование профиля**
   - у пользователя появились отдельные поля `Имя` и `Фамилия`;
   - в профиле можно самостоятельно сохранить их;
   - `display_name` автоматически синхронизируется для старых частей интерфейса и админки.

3. **Избранные фотографии**
   - избранное перенесено из `localStorage` в Neon;
   - сохраняется на уровне AGAYO ID и синхронизируется между устройствами;
   - используются реальные фотографии `media_photos`, загруженные через админку;
   - при удалении фотографии её избранные связи удаляются каскадно;
   - незалогиненный пользователь по сердечку отправляется на вход и возвращается назад.

4. **Сводка в админке по датам**
   - быстрые кнопки `Сегодня` и `Вчера`;
   - выбор произвольной даты;
   - выбор периода `С — По`;
   - за период считаются оплаченные заказы, новые пользователи, проходы по билетам, ошибки/отмены оплат и выручка (если есть право `view_revenue`);
   - расчёт суток идёт по часовому поясу `Europe/Moscow`.

## Проверка после деплоя

- Админ → Команда → выдать роль/права новому или существующему пользователю — без ошибки CHECK.
- Профиль → Настройки → задать Имя и Фамилию → обновить страницу — значения сохраняются.
- Галерея → поставить сердце → открыть профиль/избранное → фото отображается; войти тем же AGAYO ID на другом устройстве — избранное остаётся.
- Админ → Обзор → проверить `Сегодня`, `Вчера`, одну произвольную дату и диапазон дат.
